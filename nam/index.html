NAM A2 Finder

Find the best Neural Amp Modeler A2 captures that will actually run on a small machine.

1 Your machine

Pick the box the amp will run on. Every A2 file holds two sizes: A2-Full (8 channels) and A2-Lite (3 channels). This works out which one your machine can run.

Running this page on the small machine itself? Measure it.

Open this page in the browser on the device (a Pi, a mini PC, a phone) and run the test. It plays one second of audio through networks the size of A2-Full, A2-Lite and A1-standard, in 64-sample buffers, on one core. A browser is slower than a native NAM player, so the measured numbers are a worst case; the estimate below assumes native code is a few times faster.

2 Find A2 tones on TONE3000

Searches TONE3000 for tones that have A2 models and ranks them by how many people downloaded and favorited them.

How to get a key
  1. Sign in at tone3000.com/api and create an API key. The publishable key is the one for this page; it is safe to paste here. Never paste the secret (t3k_cs_) key.
  2. Add this page's address as a redirect URI on the key: (localhost addresses always work).
  3. Paste the key above and tap Connect. TONE3000 asks you to sign in and sends you back here.

TONE3000's free tier is for non-commercial use and search is rate limited. If a search gets refused, use Pick on TONE3000, which lets you browse (and preview) on their site and brings the tone back here.

3 Audition rigs

Hear a model before you keep it. Tap Play on any TONE3000 model or checked file, or load .nam files here. Pick a rig to switch while it plays, so you can A/B them.

4 Check and rank models

Drop .nam files here, or tap Check on a TONE3000 model. Each file is read on this device (nothing is uploaded): which size it is, what it costs on your machine and how accurate the capture is (validation ESR, lower is better, when the file has it).
