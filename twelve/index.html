Presets

Omega Twelve

Import any sample or song, pick part of it, and run it through a model of a vintage sampler. Turn knobs by dragging up and down; double-tap a knob to reset it.

  • Sampler: SP-1200 (26.04 kHz, 12-bit, drop-sample pitch with E-mu's semitone table), SP-12, MPC60, S950, S612, Mirage, Clean. Picking one sets bits, rate and filter to that machine; change them after if you like. Alias lets more of the unfiltered input through the converter. Drive pushes the converter harder.
  • Filter: SSM2044 is the SP-1200's outputs 1-2 (opens on each hit, then closes), fixed 3-6 are its other outputs, None is outputs 7-8. Retrigger reopens the SSM2044 on each hit inside a loop.
  • Tuning: Tune in semitones (the hardware's own range is −16 to +15; past that is extended), Fine in cents, A4 sets the reference pitch (432, 415 for baroque, and so on).
  • Warp: Detect finds tempo and key. Stretch keeps the pitch; Speed changes pitch with tempo like the original machine.
  • Truncate keeps only the selection. Resample bounces what you hear back in as the new sample and resets the effects so nothing is applied twice.
  • Master out: EQ match to a reference track (or a typical mix), a 5-band parametric EQ, compressor, gain and a look-ahead limiter. Auto master sets all of it for the loudness target.
  • The SP engine: the SP-1200 and SP-12 run their actual circuits (anti-alias filter, output filters 3-6, the SSM2044 and the capacitor network that sweeps it after each hit), simulated from the service-manual parts, and the hardware's 8-channel DAC timing and 7-bit pitch counter. Calibration: Measured SP-12 matches a real machine's part tolerances; Service manual uses the parts as drawn. 45 rpm trick: sample sped up, played back down, so only the grit changes.
  • MIDI: notes, velocity, pitch bend, program change, MIDI learn for every control, clock start / stop. TV: Cast the live screen to a TV, or open a TV window.
  • STOP ALL stops every sound right away.
