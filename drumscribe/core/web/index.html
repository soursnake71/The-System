DRUM SCRIBE

A song link in, every drum hit and bass note out as MIDI: unquantized, with lengths, velocities, slides, every piece of the kit, and the maths of the groove.

Notes sit exactly where they were played. The main file carries a tempo map (a tempo change on every beat), so the grid follows the band in DAWs that read it (Logic, Cubase, Reaper, Studio One, Pro Tools). Ableton and FL ignore file tempos: use "Constant tempo" and set the project to the tempo above. Bass slides are legato overlaps + portamento + pitch bend (range 12).
